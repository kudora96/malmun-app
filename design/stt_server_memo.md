# 서버 받아쓰기(③) 메모 — 결정 안 함 · 비용·구현 범위만 (앱 창 2026-10-07)

## 왜 필요할 수 있나
- 안드로이드 크롬 일부 기기는 「녹음 + 크롬 받아쓰기」를 동시에 못 함 → 지금은 **받아쓰기만** 자동 대체(1007.94 · 글자 점수만 · 리듬·비교·내 목소리 없음).
- 서버 받아쓰기면 **녹음 파일 하나로** 글자 점수 + 리듬 + 비교 + 내 목소리를 모든 기기에서 똑같이 줄 수 있음.

## 후보
| 서비스 | 대략 값(2026 기준 공개 가격 · 확인 필요) | 한국어 | 비고 |
|---|---|---|---|
| OpenAI 음성 받아쓰기(whisper 계열 API) | 1분 ≈ 0.6센트 | 좋음 | 파일 올려 결과 받기 · 단어 시각(타임스탬프) 가능 |

| Azure Speech | 1분 ≈ 1.7센트 | 좋음 | 발음 평가(Pronunciation Assessment) 기능 있음 — 점수 자체를 줄 수도 |

- 한 번 말하기 ≈ 3~10초 → 1번당 0.05~0.4센트. 학습자 1명이 하루 100번 = 하루 5~40센트.
- 학습자 1,000명 × 하루 100번이면 하루 50~400달러 → **무료 구간·하루 상한·기기당 횟수 제한**이 꼭 있어야 함.

## 구현 범위(앱 창 추정)
1. **중계 서버 필요**(키를 앱에 넣으면 안 됨): Cloudflare Worker 하나(R2 와 같은 계정) — 녹음 받기 → 받아쓰기 API 호출 → 글 + 낱말 시각 돌려줌 · 하루 상한·기기당 횟수 · 키는 Worker 비밀값. 반나절~하루.
2. 앱: 받아쓰기 길 하나 더(지금 「같이」·「받아쓰기만」 옆에 「서버」) · 결과를 지금 점수 식에 그대로 넣음 · 실패하면 지금 방식으로. 반나절.
3. 개인정보: 학습자 목소리가 외부(미국 서버)로 감 → 첫 사용 때 안내·동의 · 저장 안 함(받아쓰기 뒤 바로 버림) 문구. 120개국 기준 검토 필요.
4. 시험: 점검 도구(가짜 서버) · 실제 기기 3~4종.

## 10-10 본부 갱신 — 투덜이 「ㅇ」(2안 준비 시작) · 「1번안 잘 보고 하자」
